    Device

    Keep screen onStops the screen dimming while this page is open.
    Install as an app On iPhone: open this page in Safari, tap Share, then Add to Home Screen. On Android or desktop Chrome: use the browser menu, then Install app.

    Saving and sync

    Saved on this device Every tick saves instantly in this browser. An installed home-screen app on iPhone has its own storage, separate from Safari. Use sync or a backup code to bring your progress across.
    Sync between devices Optional. Progress is stored in a private gist on your own GitHub account, so there is no server. Create a classic personal access token at github.com/settings/tokens with only the gist scope, then paste it on each device. The token stays in this browser and can be revoked any time.
    Not connected
    Backup Download a file you can keep anywhere, or copy a short code.
    ResetClears every tick on this device. Settings stay. If sync is on, the reset syncs too.
