Trophies

    Sync between devices

    Optional. Progress is stored in a private gist on your own GitHub account, so there is no server and nothing to sign up for. The token stays in this browser and you can revoke it on GitHub at any time.
    Not connected
    1. Create a classic token on GitHub with only the gist scope.
    2. Copy it, paste it below and press Connect. Repeat on each device.

    This device

    Saved on this device Every tick saves instantly in this browser. An installed home-screen app on iPhone has its own storage, separate from Safari. Use sync or a backup to bring your progress across.
    Keep screen onStops the screen dimming while this page is open.
    Install as an app On iPhone: open this page in Safari, tap Share, then Add to Home Screen. On Android or desktop Chrome: use the browser menu, then Install app.

    Reset

    Clears every tick on this device. Appearance and other settings stay. If sync is on, the reset syncs to your other devices too, so download a backup first if you might want it back.
